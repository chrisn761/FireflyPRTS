# 科研入门第一期：如何查找适合投稿的期刊

对于刚开始接触科研的同学来说，完成论文写作只是第一步。如何找到一个适合自己研究方向、文章类型和研究质量的期刊，同样非常重要。

本期主要介绍如何使用 [LetPub](https://www.letpub.com.cn/index.php?page=journalapp&view=search&searchsort=relevance&searchname=) 查询和筛选期刊，并以目前正在投稿的 [Information Fusion](https://www.sciencedirect.com/journal/information-fusion) 为例，说明确定目标期刊后还需要关注哪些信息。

## 一、为什么需要提前了解期刊

不同期刊的研究方向、收稿范围、影响力、审稿速度和投稿要求都不一样。如果没有提前了解期刊，可能会遇到以下问题：

- 文章研究方向与期刊不匹配；
- 文章类型不符合期刊要求；
- 期刊不接收当前研究领域的稿件；
- 文章水平与期刊定位差距较大；
- 投稿后因为格式或范围问题被直接拒稿。

因此，在开始写作或准备投稿时，就可以提前了解相关期刊。

## 二、使用 LetPub 查询期刊

打开 [LetPub 期刊查询](https://www.letpub.com.cn/index.php?page=journalapp&view=search&searchsort=relevance&searchname=)，可以根据以下关键信息查询期刊：

![图 1. LetPub 期刊查询页面。](./letpub.png)

- **期刊名称**：如果导师已经指定了目标期刊，可以直接搜索期刊名称；
- **大类学科**：期刊所属的一级学科，例如“计算机科学”或“工程技术”；
- **小类学科**：大类学科下更具体的研究方向，例如“生物医学工程”；
- **新锐期刊分区表**：用于查看部分新兴期刊的分区信息；
- **是否 Open Access（OA）**：OA 期刊通常允许读者免费阅读论文，但作者可能需要支付文章处理费（APC）。

对于医工交叉领域的研究，可以尝试在检索时选择：

```text
大类学科：计算机科学
小类学科：生物医学工程
```



### 小 Tip

关于版面费：非 OA 期刊是最常见的投稿选择。通常情况下，作者不需要额外支付文章处理费。不过，部分期刊可能存在超页费、彩色图片费等特殊费用。以部分 IEEE 期刊为例，论文采用双栏排版，超过规定页数（通常为 8 页）时需要支付超页版面费。具体页数和收费标准需要以目标期刊的官方要求为准。

关于期刊分区：四区论文的认可度通常相对较低，部分导师可能认为发表四区论文会影响学术评价。在研究质量和时间允许的情况下，建议尽量将目标设定为至少三区期刊。


## 三、确定目标期刊后需要查看哪些信息

如果通过 LetPub 找到了一本合适的期刊，下一步不能只看分区和影响因子，还需要进入期刊官方网站，进一步确认投稿要求。

以 [Information Fusion](https://www.sciencedirect.com/journal/information-fusion) 为例，可以从以下几个方面进行了解。

![图 2. Information Fusion 期刊主页及其基本信息。](./information%20fusion.png)

### 1. 查看实时影响因子和分区

LetPub 等网站通常会整理期刊的影响因子、分区、审稿周期和录用率等信息。但第三方平台显示的数据存在滞后或估算误差，正式投稿前建议确认：

- 期刊当前的影响因子；
- 新锐分区与中科院分区；
- 期刊近期是否发生降区或升区，是否被预警过；
- 所在单位认可哪一种分区标准。


### 2. 查看 Author Guidelines（作者指南）

期刊官方网站中的 **Author Guidelines** 是投稿前最重要的参考内容。最稳妥的方式是以期刊官网当前版本的作者指南为准，而不是依赖已发表的论文或第三方经验。

通常需要确认以下要求：

- 论文结构、章节、摘要和关键词格式；
- 图表、参考文献及文件格式要求；
- 是否需要 Graphical Abstract 或 Highlights；
- 是否需要 Cover Letter 及利益冲突声明；
- 伦理审查、数据共享要求及开放获取政策。

以博主在投的一区Top Information Fusion 为例，投稿前应进入期刊官方网站，找到 **Guide for Authors** 或 **Author Guidelines** 页面，查看最新投稿要求。

![图 3. Information Fusion 的作者指南（Guide for Authors）页面。](./guideline.png)

<strong style="color: #dc2626;">重要提示：每一本 Elsevier 期刊的作者指南页面开头通常都提供 “Print Guide as PDF” 功能，可直接下载作者指南 PDF；下载后也可以让 Codex 帮你分析重点要求。关于 Codex 的使用教程，我会在后续内容中更新。</strong>

论文格式不能只参考已经发表的论文，也不能完全依赖 LetPub 上的经验总结。最稳妥的方式是以期刊官网当前版本的作者指南为准。

### 3. 了解期刊排版格式

不同出版社和期刊的排版方式可能不同，不能简单地认为所有期刊都使用相同的模板。投稿前最重要的是确认初次投稿阶段的排版要求。

#### IEEE 期刊

IEEE 是一个重要的工程技术和电子信息领域学术组织，同时也出版大量学术期刊和会议论文集。

IEEE 期刊通常采用双栏排版，对页面尺寸、字体字号、图表宽度、参考文献和页数有明确要求。投稿时需要从 IEEE 官方网站下载对应的 Word 或 LaTeX 模板。

#### Elsevier 期刊

Elsevier 是一家大型国际学术出版商，Information Fusion 就是 Elsevier 旗下的期刊。

许多 Elsevier 期刊在初次投稿阶段对排版格式相对宽松，通常允许单栏提交，录用后由出版社统一排版。不过，部分期刊可能要求特定模板或单独提交附加材料。


### 4. 找到正确的投稿系统

期刊官方网站中的 **Submit your paper** 等按钮通常会链接到正式投稿系统。投稿时建议务必从期刊官方网站进入，避免通过不明链接投稿。

不同出版社使用的投稿系统有所不同：

- **IEEE 期刊**：常使用 IEEE Author Portal 或 ScholarOne；
- **Elsevier 期刊**：常使用 Editorial Manager 或 Elsevier 投稿平台；
- **Springer/Wiley**：拥有各自独立的投稿系统。

投稿系统通常用于：

- 注册作者账号；
- 填写论文标题和摘要；
- 添加作者和单位信息；
- 选择研究领域；
- 上传主文稿；
- 上传图表和补充材料；
- 上传 Cover Letter；
- 填写推荐审稿人；
- 处理利益冲突声明；
- 确认投稿并获取稿件编号；
- 查看审稿进度和编辑决定。

以 Information Fusion 为例，可以在 LetPub 的期刊详情界面中找到“期刊投稿网址”，并通过该链接进入期刊对应的 **Editorial Manager** 系统。

从今年开始，部分 Elsevier 期刊会在 Editorial Manager 中再次跳转至 Elsevier 自己的期刊投稿流程页面，以完成新稿件的实际提交。不过，Editorial Manager 仍然是投稿过程中不可或缺的中转平台：可以在这里查询稿件状态、查看编辑决定，并向编辑发送催审稿或其他与稿件相关的邮件。

![图 4. Information Fusion 跳转至 Editorial Manager 后的投稿系统入口页面。](./submit.png)

上图是进入 Editorial Manager 后的期刊投稿系统主页，主要用于查看投稿说明、稿件状态和可执行的操作。准备新投稿时，选择 **Submit New Manuscript** 即可进入新稿件提交流程。

![图 5. 选择 “Submit New Manuscript” 后进入的 Information Fusion 新稿件提交页面。](./IF.png)

该页面用于按步骤填写稿件信息、作者信息、分类和声明，并上传论文及相关附件；它与图 4 的区别是，图 4 是投稿系统入口页，图 5 则是实际的新稿件提交流程页面。

在提交过程中，期刊可能要求上传以下文件：

- 主文稿（Manuscript）；
- 封面信（Cover Letter）；
- 图表或补充材料；
- Highlights、Graphical Abstract 或数据可用性声明（如期刊要求）；
- 其他与伦理、利益冲突或作者贡献相关的文件。

![图 6. Information Fusion 投稿系统中的文件上传要求示例。](./file.png)

### 5. 通过评论区了解期刊风评

LetPub 的评论区可以作为了解期刊投稿体验的参考。通过近期评论，可以大致了解审稿速度、修回情况以及是否存在隐形费用。

评论中通常可以看到投稿者分享的：

- 初审和外审时间；
- 编辑处理速度；
- 审稿意见数量；
- 大修和小修情况；
- 投稿到录用所需时间；
- 录用后在线发表速度；
- 编辑和审稿人的处理风格；
- 是否存在超页费或其他费用。

常见投稿状态对照如下：

| 投稿状态 | 含义 |
| --- | --- |
| `Submitted to Journal` | 已经完成投稿，稿件进入系统 |
| `With Editor` | 稿件正在等待编辑处理，初筛可能需要数天至数周 |
| `Under Review` | 稿件已经送交审稿人，外审可能需要几周到几个月 |
| `Required Reviews Completed` | 审稿意见基本收齐，等待编辑决定 |
| `Decision in Process` | 编辑正在作出决定 |
| `Revise` | 需要修改后重新提交 |
| `Accepted` | 论文已经录用 |


一篇论文通常会经历以下投稿阶段：

```text
投稿
  ↓
编辑初筛
  ↓
送外审
  ↓
收到审稿意见
  ↓
大修或小修
  ↓
再次审稿
  ↓
录用或拒稿
  ↓
排版
  ↓
在线发表
```

不同阶段所需时间差异很大：

- 编辑初筛可能只需要几天，也可能持续数周；
- 寻找审稿人可能需要数天到数周；
- 外审可能需要几周到几个月；
- 大修后的再次审稿可能持续更长时间；
- 录用后的排版和在线发表也需要一定时间。


### 6. 投稿前的基本检查清单

确定目标期刊后，可以按照下面的清单进行最后检查：

- [ ] 研究方向与期刊范围匹配；
- [ ] 文章类型符合期刊要求；
- [ ] 已查看最新的 Author Guidelines；
- [ ] 已确认影响因子和分区信息；
- [ ] 已确认是否为 OA 期刊；
- [ ] 已了解 APC 及超页费情况；
- [ ] 已准备符合要求的论文格式；
- [ ] 已准备 Cover Letter；
- [ ] 已准备 Highlights 或 Graphical Abstract（如果需要）；
- [ ] 已确认官方投稿系统地址；
- [ ] 已检查作者、单位和通信作者信息；
- [ ] 已检查图表、参考文献和补充材料；
- [ ] 已确认论文没有重复投稿或一稿多投问题。

总的来说，LetPub 适合进行期刊初步筛选，期刊官方网站适合确认正式投稿要求，评论区则可以帮助了解真实投稿体验。

将这三种信息结合起来，可以大幅减少选刊和投稿过程中不必要的问题。
